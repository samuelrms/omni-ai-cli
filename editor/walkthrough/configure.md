# Connect accounts and keys

- `ai --setup` — first-run guide: what to log in and configure.
- `ai doctor` — health check: accounts, API keys, tools.
- `ai --account add <name>` — add a Claude account.
- `ai --key <tool>` — add an API key (OpenRouter, Grok, …).

Pick the tool and permission mode at the bottom of the chat.
