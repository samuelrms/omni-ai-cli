# Open the chat

- **Sidebar:** the Omni AI icon in the activity bar.
- **Editor tab:** command "Omni AI: Open chat in editor".
- **Shortcuts:** chat `cmd/ctrl+shift+a`, editor tab `cmd/ctrl+alt+a`.
- Type `/` for commands, `+` to attach files as context.
- History view lists past conversations across tools; "Continue in chat" resumes one.
