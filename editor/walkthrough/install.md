# Install the Omni AI CLI

The extension is a thin layer over the `ai` command — install it once:

```bash
npm install -g omni-ai-cli
# or
brew install samuelrms/tap/omni-ai-cli
# or
curl -fsSL https://raw.githubusercontent.com/samuelrms/omni-ai-cli/main/get.sh | bash
```

If `ai` is missing, the extension also offers to install it for you.
